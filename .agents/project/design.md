2. DIRETRIZES DE APLICAÇÃO VISUAL (Classes Tailwind)

- Fundos (Backgrounds): Use bg-purple-50 ou bg-purple-100 para fundos principais, garantindo um visual limpo. Use bg-blue-900 para secções de rodapé (footer) ou blocos de destaque escuros.
- Textos: Use text-blue-900 para títulos e textos principais (alto contraste). Aplique a classe font-serif exclusivamente para Cabeçalhos (H1, H2, H3, logótipos e destaques elegantes). Aplique font-sans para o corpo do texto, parágrafos, botões e menus.
- Botões e Destaques (Call to Action): Use bg-orange-500 com hover em hover:bg-orange-600 e texto escuro text-blue-900 (contraste 9,5:1 — WCAG AAA) para atrair a atenção do utilizador com legibilidade garantida em campo.
